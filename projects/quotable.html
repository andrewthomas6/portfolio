Overview

Many people take joy in recording profound advice or memorable lines from friends, but doing it quickly and sharing those quotes easily is a real challenge. Quotable was built to solve that problem.

The platform originally began as an HTML/CSS and TypeScript site, but we rebuilt it as an iOS and Android app to increase accessibility and reach more users. The app runs on a React Native frontend with a PHP backend. The beauty of an ongoing project like this is that once my co-developers and I laid the foundation, every new feature ticket has become a chance to dig deeper into the intricacies of UI/UX design. Having a clean software architecture has proved essential through a few large refactors, and our API has evolved into a systematic query-and-response system to cleanly access our SQL database. Managing a live platform (and debugging it when it goes down) has given me direct, hands-on experience in networking and server setup. It's proven that while downtime is frustrating, failures definitely teach you a lot more about integration and diagnostic tools.

Key Deliverables & Specs

  • Cross-platform iOS/Android app
  • Structured PHP/SQL database API system
  • Live platform hosting and network management. Supporting 300+ users.
